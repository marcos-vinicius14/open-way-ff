# Plan 02-02: Widgets Polimórficos, Perfil de Fábrica default_freefire.json, ProfileManager e Migração de Schema

**As a** jogador competitivo e criador de mapas de teclas no Free Fire,  
**I want to** salvar e carregar perfis hierárquicos completos com múltiplos botões (WASD, mira, tiro, agachar, pular) e alternar perfis rapidamente via CLI ou gerenciar arquivos externos,  
**so that** minhas configurações competitivas fiquem organizadas, seguras e prontas para sincronização com o overlay visual e o launcher.

<objective>
Implementar a modelagem polimórfica de widgets (`TapWidget`, `DPadWidget`, `AimWidget`, `FireWidget`), refatorar o `WayFireProfile` para suportar o schema hierárquico completo com compatibilidade retroativa para a Fase 1, construir o perfil de fábrica pronto para jogo `default_freefire.json`, desenvolver a classe `ProfileManager` com armazenamento em `~/.config/wayfire/profiles/` e proteção contra path traversal, e expor os subcomandos de perfil na CLI (`wayfire profile`).

Purpose: Atender ao requisito MAP-01 e às decisões D-13 a D-16, estabelecendo o contrato de dados consumido pelo Overlay da Fase 3 e pelo Launcher da Fase 4.
Output: Módulos `src/wayfire/config/widgets.py` e `src/wayfire/config/profile_manager.py`, refatoração de `src/wayfire/config/profile.py`, expansão da CLI e testes em `tests/test_profile_manager.py`.
</objective>

    1. Criar `src/wayfire/config/profile_manager.py` (per D-16 e Research §4.5):
       - Função de sanitização de segurança `sanitize_profile_name(name: str) -> str`:
         - Extrai `stem = Path(name).stem`.
         - Aplica regex restritivo `clean = re.sub(r'[^a-zA-Z0-9_-]', '', stem)`.
         - Se o resultado for vazio ou contiver sequências perigosas, levanta `ValueError(f"Nome de perfil inválido: '{name}'")`.
         - Retorna o nome sanitizado.
       - Classe `ProfileManager`:
         - `__init__(self, profiles_dir: Optional[Path | str] = None, active_file: Optional[Path | str] = None)`:
           - Diretório padrão: `Path.home() / ".config" / "wayfire" / "profiles"`
           - Arquivo ativo padrão: `Path.home() / ".config" / "wayfire" / "active_profile"`
           - Cria automaticamente o diretório se não existir.
           - Se o diretório estiver vazio (nenhum `.json`), gera automaticamente o `default_freefire.json` via `create_default_profile().save(default_path)`.
           - Se `active_file` não existir, grava `"default_freefire"`.
         - `list_profiles() -> list[str]`: lista todos os arquivos `.json` no diretório e retorna seus nomes sem extensão em ordem alfabética.
         - `get_profile_path(name: str) -> Path`: retorna `self.profiles_dir / f"{sanitize_profile_name(name)}.json"`.
         - `load_profile(name_or_path: str | Path) -> WayFireProfile`: se for um arquivo existente, carrega via `WayFireProfile.load(path)`; se for um nome, busca via `get_profile_path(name)`.
         - `save_profile(profile: WayFireProfile, name: Optional[str] = None) -> Path`: utiliza `name or profile.profile_name`, sanitiza o nome e salva no diretório de perfis.
         - `get_active_profile_name() -> str`: lê o conteúdo limpo de `self.active_file`; fallback para `"default_freefire"` se inexistente ou inválido.
         - `set_active_profile(name: str) -> None`: sanitiza `name`, valida se o perfil correspondente existe em disco (levanta `FileNotFoundError` se não existir), e grava o nome em `self.active_file`.
         - `get_active_profile() -> WayFireProfile`: carrega o perfil retornado por `get_active_profile_name()`.
         - `export_profile(name: str, target_path: str | Path) -> Path`: carrega o perfil especificado e salva uma cópia em `target_path`.
         - `import_profile(source_path: str | Path, name: Optional[str] = None) -> Path`:
           - Valida se `source_path` existe.
           - Lê e valida o JSON criando uma instância de `WayFireProfile`.
           - Determina o nome de destino via `sanitize_profile_name(name or profile.profile_name or Path(source_path).stem)`.
           - Salva no diretório de perfis e retorna o caminho salvo.
         - `delete_profile(name: str) -> bool`: sanitiza o nome; se for `"default_freefire"`, levanta `ValueError("O perfil padrão de fábrica não pode ser excluído.")`; remove o arquivo e retorna True se existia.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User / File System -> Storage Path | Nomes de arquivos de perfil fornecidos via CLI ou arquivos importados. |
| Untrusted JSON File -> Data Model | Deserialização de arquivos JSON contendo configurações e definições de widgets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Tampering / Information Disclosure | Profile Path Traversal | high | mitigate | Sanitizar estritamente nomes de perfis usando `re.sub(r'[^a-zA-Z0-9_-]', '', stem)` e validar que o caminho resolvido pertence estritamente a `profiles_dir`. |
| T-02-06 | Denial of Service | Malformed / Corrupted JSON | medium | mitigate | Capturar `json.JSONDecodeError` e `KeyError` com fallback gracioso para perfil padrão e mensagens de erro descritivas ao usuário. |
| T-02-07 | Tampering | Arbitrary Code Execution / Deserialization | high | mitigate | Rejeitar deserialização não controlada; instanciar widgets unicamente através de `WidgetFactory._REGISTRY` tipado com classes conhecidas (`TapWidget`, `DPadWidget`, `AimWidget`, `FireWidget`). |
| T-02-08 | Denial of Service | Accidental Factory Default Deletion | low | mitigate | Bloquear expressamente remoção de `default_freefire` no método `delete_profile()`. |
