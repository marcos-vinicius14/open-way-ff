# Plan 02-01: Waydroid Controller, Resoluções Esticadas, Spoofing ROG Phone e Escalonamento Dinâmico

**As a** jogador competitivo de Free Fire no Linux,  
**I want to** controlar o ciclo de vida do Waydroid programaticamente, aplicar resoluções esticadas (1440x1080 4:3) e desbloquear 90/120 FPS via spoofing ASUS ROG Phone sem comandos manuais,  
**so that** o jogo inicie otimizado, na proporção competitiva ideal e com o motor de mira calibrado dinamicamente para as dimensões ativas da tela.

<objective>
Implementar o controlador de ciclo de vida do Waydroid (`WaydroidController`), o protocolo desacoplado de execução de comandos (`CommandRunner`), a aplicação idempotente de resoluções esticadas com reinício automático de sessão, o spoofing de hardware do ASUS ROG Phone 5 com backup e restauração, a reconfiguração dinâmica de resolução no `TouchInjector` e `AimEngine`, e a integração dos novos subcomandos na CLI (`wayfire launch`, `wayfire stop`, `wayfire spoof`).

Purpose: Atender aos requisitos WAY-01, WAY-02 e WAY-03, e às decisões D-01 a D-12, viabilizando uma experiência de inicialização fluida e competitiva sem atritos de terminal.
Output: Módulos `src/wayfire/waydroid/controller.py`, métodos `set_screen_dimensions` no Core, novos subcomandos na CLI e suítes de teste herméticas com mocks em `tests/test_waydroid_controller.py` e `tests/test_scaling.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python Process -> System Shell / Subprocess | Execução de comandos do sistema (`waydroid`, `systemctl`, `pkexec`). |
| Python Process -> Android Runtime Props | Injeção de propriedades de hardware (`ro.product.*`, `persist.waydroid.*`). |
| Host Filesystem -> Config Directory | Armazenamento de backup de propriedades em `~/.config/wayfire/device_backup.json`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
