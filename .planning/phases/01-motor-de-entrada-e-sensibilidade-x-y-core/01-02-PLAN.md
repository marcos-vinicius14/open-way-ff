# Plan 01-02: Captura de Periféricos (Mouse/Teclado) e Motor de Sensibilidade X/Y

**As a** jogador competitivo de Free Fire no Linux,  
**I want to** travar o mouse na tela com a tecla F1 e movimentar a mira com multiplicadores independentes para os eixos horizontal e vertical (puxada de capa),  
**so that** eu possa puxar tiros na cabeça com deslocamento mínimo do mouse e destravar o cursor instantaneamente para navegar nos menus do jogo.

<objective>
Implementar o subsistema de captura de baixo nível de mouse e teclado em `/dev/input/event*` com autodetecção inteligente, controle de trava exclusiva (`ioctl EVIOCGRAB`) no `F1`, e o motor de sensibilidade com calibração independente $Sens_X$ e $Sens_Y$, filtro de suavização exponencial (EMA) e acumulador de subpixel fracionário.

Purpose: Atender aos requisitos CORE-02 e CORE-03 e decisões D-01, D-02, D-03, D-04, D-09, D-10, D-11 e D-12, assegurando controle de cursor responsivo, prevenção contra travamento de mouse no host (host lockout) e micro-precisão de mira.
Output: Módulos `src/wayfire/core/mouse_capture.py` e `src/wayfire/core/aim_engine.py` (componente `AimProcessor`), acompanhados por suas suítes de testes unitários herméticos.
</objective>

    1. Criar `src/wayfire/core/mouse_capture.py` com:
       - Função `detect_input_devices(device_paths: Optional[list[str]] = None) -> tuple[Optional[str], Optional[str]]` per D-02:
         - Itera sobre os caminhos em `device_paths` ou `evdev.list_devices()`.
         - Lê capabilities de cada dispositivo:
           - Identifica mouse: possui `ecodes.EV_REL` com `REL_X` e `REL_Y`, possui `ecodes.EV_KEY` com `BTN_LEFT`, e NÃO possui `ecodes.EV_ABS` (descartando touchpads, trackpoints e mesas digitalizadoras).
           - Identifica teclado: possui `ecodes.EV_KEY` contendo `KEY_A` e `KEY_SPACE`.
         - Retorna tupla `(mouse_path, keyboard_path)`.
       - Classe `InputCaptureManager(mouse_dev: Optional[Any] = None, keyboard_dev: Optional[Any] = None, suspend_key: int = ecodes.KEY_F1)`:
         - Estado inicial: `is_aim_locked: bool = False` (inicia obrigatoriamente no estado suspenso per D-04).
         - Atributos para callbacks: `on_mouse_move: Optional[Callable[[int, int], None]] = None`, `on_mouse_button: Optional[Callable[[int, int], None]] = None`, `on_hotkey: Optional[Callable[[int], None]] = None`, `on_lock_changed: Optional[Callable[[bool], None]] = None`.
         - Gestão de trava exclusiva (`ioctl EVIOCGRAB` per D-03):
           - `grab_mouse()`: se `mouse_dev` presente e `not is_grabbed`, chama `mouse_dev.grab()` e define `is_grabbed = True`.
           - `ungrab_mouse()`: se `mouse_dev` presente e `is_grabbed`, chama `mouse_dev.ungrab()` e define `is_grabbed = False`.
         - Método `toggle_aim_lock() -> bool`:
           - Inverte `is_aim_locked`.
           - Se `is_aim_locked` for True: invoca `grab_mouse()`.
           - Se `is_aim_locked` for False: invoca `ungrab_mouse()`.
           - Aciona callback `on_lock_changed(is_aim_locked)` se registrado.
           - Retorna novo estado.
         - Multiplexação I/O via `selectors.DefaultSelector`:
           - Registra os descritores de arquivo de `mouse_dev` e `keyboard_dev` para leitura (`selectors.EVENT_READ`).
           - Método `poll_events(timeout: float = 0.001) -> list[tuple[str, Any]]`: consulta o seletor sem bloquear a CPU; processa `InputEvent` lidos; detecta pressionamento da `suspend_key` (`value == 1`) e invoca `toggle_aim_lock()`; roteia `REL_X`/`REL_Y` para `on_mouse_move` apenas se `is_aim_locked` for True; roteia botões do mouse para `on_mouse_button`.
         - Mecanismos de segurança de sinal:
           - Método `setup_signal_handlers()`: intercepta `signal.SIGINT` e `signal.SIGTERM` para invocar obrigatoriamente `cleanup()` antes do encerramento do processo, prevenindo host lockout do mouse no desktop.
           - Método `cleanup()`: executa `ungrab_mouse()`, desregistra do seletor e fecha descritores.
    2. Criar `tests/test_mouse_capture.py` com mocks herméticos de `InputDevice`:

       - `test_f1_toggle_grab_ungrab`: simula evento `KEY_F1`, verificando que `is_aim_locked` muda para `True` e `grab()` é chamado; simula novo `KEY_F1`, verificando reversão para `False` e chamada de `ungrab()`.
       - `test_mouse_deltas_ignored_when_suspended`: verifica que deltas de mouse (`REL_X`, `REL_Y`) não são despachados para `on_mouse_move` quando o motor estiver no estado suspenso.
       - `test_cleanup_guarantees_ungrab`: valida que a invocação de `cleanup()` ou handler de sinal sempre invoca `ungrab()`.

    1. Criar `src/wayfire/core/aim_engine.py` contendo a classe `AimProcessor`:
       - Assinatura do construtor:
         `def __init__(self, sens_x: float = 1.45, sens_y: float = 3.20, smoothing: bool = True, alpha: float = 0.80, invert_y: bool = False)`
         com valores padrão calibrados para Free Fire ("puxada de capa" per D-09 e D-10).
       - Estado interno:
         `self.prev_dx: float = 0.0`, `self.prev_dy: float = 0.0` (histórico para filtro EMA),
         `self.acc_x: float = 0.0`, `self.acc_y: float = 0.0` (acumulador fracionário de subpixel per D-11).
       - Método `process_delta(raw_dx: int, raw_dy: int) -> tuple[int, int]`:
         1. Aplicar inversão vertical opcional per D-12:
            `dy_in = -raw_dy if self.invert_y else raw_dy`
         2. Aplicar filtro de suavização exponencial (EMA) per D-10:
            Se `self.smoothing` for True:
              `filtered_dx = self.alpha * raw_dx + (1.0 - self.alpha) * self.prev_dx`
              `filtered_dy = self.alpha * dy_in + (1.0 - self.alpha) * self.prev_dy`
              `self.prev_dx = filtered_dx; self.prev_dy = filtered_dy`
            Senão:
              `filtered_dx = float(raw_dx); filtered_dy = float(dy_in)`
         3. Aplicar multiplicadores de sensibilidade independentes per D-09:
            `scaled_dx = filtered_dx * self.sens_x`
            `scaled_dy = filtered_dy * self.sens_y`
         4. Acumular subpixels fracionários per D-11:
            `self.acc_x += scaled_dx`
            `self.acc_y += scaled_dy`
         5. Extrair deslocamento inteiro preservando o sinal:
            `step_x = math.trunc(self.acc_x)`
            `step_y = math.trunc(self.acc_y)`
         6. Retornar resto decimal ao acumulador:
            `self.acc_x -= step_x`
            `self.acc_y -= step_y`
         7. Retornar `(step_x, step_y)`.
       - Métodos de ajuste dinâmico em tempo de execução:
         - `set_sensitivity(sens_x: Optional[float] = None, sens_y: Optional[float] = None) -> None`: atualiza valores garantindo limite mínimo de 0.05.
         - `reset_state() -> None`: zera `acc_x`, `acc_y`, `prev_dx`, `prev_dy`.
    2. Criar `tests/test_aim_engine.py`:
       - `test_sensitivity_scaling_independent`: valida que com $Sens_X = 1.0$ e $Sens_Y = 2.5$, deltas iguais $(10, 10)$ resultam em saídas proporcionais com eixo Y maior para puxada de capa per D-09.
       - `test_subpixel_accumulation_preserves_micro_movements`: envia deltas unitários pequenos com sensibilidade fracionária baixa ($dx=1$, $Sens_X=0.35$); verifica que a cada 3 frames o acumulador emite 1 pixel sem truncar para 0, comprovando ausência de pixel skipping em snipers per D-11.
       - `test_ema_smoothing_attenuates_jitter`: envia sequência alternada de deltas com ruído de alta frequência e valida que a curva resultante tem amplitude atenuada quando `smoothing=True`.
       - `test_invert_y_toggle`: verifica que `invert_y=True` inverte o sinal do deslocamento vertical per D-12.
       - `test_reset_state_clears_residue`: valida que chamar `reset_state()` elimina qualquer resíduo fracionário armazenado.
  </action>

| Mouse Grab -> Host Desktop Windowing | Captura exclusiva via `ioctl EVIOCGRAB` remove o controle do cursor do compositor desktop do host. |
