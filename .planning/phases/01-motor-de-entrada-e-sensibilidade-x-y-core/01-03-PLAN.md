    1. Expandir `src/wayfire/core/aim_engine.py` com a classe `AimEngine`:
       - Parâmetros de inicialização:
         `processor: AimProcessor`,
         `screen_width: int = 1920`, `screen_height: int = 1080`,
         `anchor_norm_x: float = 0.65`, `anchor_norm_y: float = 0.50` (coordenadas normalizadas da âncora da câmera per D-07),
         `radius_norm: float = 0.20` (raio virtual normalizado da área de mira),
         `fire_button_norm: tuple[float, float] = (0.80, 0.75)` (posição normalizada do botão de tiro no HUD per D-16),
         `threshold_ratio: float = 0.75` (limiar de reset a 75% da borda per D-06).
       - Cálculo de coordenadas e limiares absolutos em pixels:
         `anchor_px = (int(anchor_norm_x * screen_width), int(anchor_norm_y * screen_height))`
         `radius_px = int(radius_norm * min(screen_width, screen_height))`
         `max_dist_sq = (radius_px * threshold_ratio) ** 2`
       - Estado de rastreamento:
         `current_x: int = anchor_px[0]`, `current_y: int = anchor_px[1]`,
         `reset_count: int = 0`, `is_aim_active: bool = False`,
         `fire_slot: int = 1` (Slot 1 multitouch reservado para o gatilho de tiro per D-08 e D-16).
       - Método `start_aim(injector: TouchInjector) -> None`:
         - Se `not is_aim_active`: emite `injector.touch_down(slot=0, x=anchor_px[0], y=anchor_px[1])`, define `current_x = anchor_px[0]`, `current_y = anchor_px[1]`, e `is_aim_active = True`.
       - Método `stop_aim(injector: TouchInjector) -> None`:
         - Se `is_aim_active`: emite `injector.touch_up(slot=0)`, chama `processor.reset_state()`, e define `is_aim_active = False`.
       - Método `update_aim(raw_dx: int, raw_dy: int, injector: TouchInjector) -> tuple[int, int, bool]`:
         - Se `not is_aim_active`: invoca `start_aim(injector)`.
         - Calcula deltas via `processor.process_delta(raw_dx, raw_dy)` obtendo `(step_x, step_y)`.
         - Se `step_x == 0 and step_y == 0`: retorna `(current_x, current_y, False)`.
         - Calcula posição candidata: `cand_x = current_x + step_x`, `cand_y = current_y + step_y`.
         - Calcula distância euclidiana da âncora:
           `dist_sq = (cand_x - anchor_px[0]) ** 2 + (cand_y - anchor_px[1]) ** 2`
         - Se `dist_sq >= max_dist_sq` (atingiu limiar de 75% da borda virtual per D-06):
           1. Invoca `injector.reset_slot_cycle(slot=0, anchor_x=anchor_px[0], anchor_y=anchor_px[1], pause_sec=0.001)` per D-05.
           2. Incrementa `reset_count += 1`.
           3. Restaura coordenadas para a âncora: `current_x = anchor_px[0]`, `current_y = anchor_px[1]`.
           4. Limpa histórico de inércia do processador chamando `processor.reset_state()`.
           5. Retorna `(current_x, current_y, True)` (flag booleana sinalizando reset executado).
         - Senão (movimento normal dentro da área de segurança):
           1. Emite `injector.touch_move(slot=0, x=cand_x, y=cand_y)`.
           2. Atualiza `current_x = cand_x`, `current_y = cand_y`.
           3. Retorna `(current_x, current_y, False)`.
       - Método `handle_mouse_button(code: int, value: int, injector: TouchInjector) -> None` per D-16:
         - Se `code == ecodes.BTN_LEFT`:
           - Se `value == 1` (clique pressionado): calcula coordenadas em pixels do botão de tiro `(int(fire_button_norm[0] * screen_width), int(fire_button_norm[1] * screen_height))` e emite `injector.touch_down(slot=fire_slot, x=fire_x, y=fire_y)`.
           - Se `value == 0` (clique solto): emite `injector.touch_up(slot=fire_slot)`.
    2. Expandir `tests/test_aim_engine.py`:

       - `test_continuous_360_rotation_infinite`: simula rotação rápida unidirecional por 150 ciclos; verifica que múltiplos resets atômicos acontecem sem travar a mira, mantendo os toques sempre contidos dentro da zona circular sem acúmulo de erro ou explosão de coordenadas.
       - `test_fire_button_slot_1_concurrency`: testa eventos de pressionar e soltar o botão esquerdo (`BTN_LEFT`); valida que o Slot 1 emite `touch_down` e `touch_up` nas coordenadas corretas do botão de tiro simultaneamente com a mira ativa no Slot 0, sem afetar o estado da câmera.
