# Plan 03-02: Editor Visual Estilo GG Mouse Pro — Canvas Interativo, Captura [ ? ], Gestos e Persistência Debounced

**As a** jogador competitivo de Free Fire no Linux,  
**I want to** posicionar e redimensionar botões na tela com duplo clique instantâneo estilo GG Mouse Pro, capturar qualquer tecla ou botão lateral do mouse e salvar tudo automaticamente no perfil,  
**so that** a calibração do meu HUD seja rápida, intuitiva e sem perda de tempo em menus complexos.

<objective>
Implementar a infraestrutura completa do editor visual interativo: o serviço de auto-save contínuo debounced (`ProfileDebounceSaver`), a barra de ferramentas retrátil superior (`FloatingTopBar`), o canvas gestual (`OverlayCanvas`) com criação por duplo clique, escuta imediata `[ ? ]`, bloqueio amigável de teclas do sistema (`F1`, `F2`, `F3`), validação rigorosa de instância única para Mira e DPad, alças de redimensionamento e atalhos de exclusão rápida.

Purpose: Cumprir o requisito UI-02 e as decisões D-03, D-05, D-06, D-07, D-08, D-13 e D-15.
Output: Módulos `src/wayfire/ui/debounce_saver.py`, `src/wayfire/ui/floating_bar.py`, `src/wayfire/ui/overlay_canvas.py`, integração em `src/wayfire/ui/overlay.py` e testes herméticos em `tests/test_debounce_saver.py` e `tests/test_overlay_canvas.py`.
</objective>

<threat_model>
### ASVS Level 1 Threat Assessment

1. **Threat — Denial of Service via Rapid Disk Thrashing / Excessive I/O (CWE-400):** Durante o ajuste visual fino (arrasto contínuo com mouse gerando 120-240 eventos/segundo), se cada evento disparasse escrita síncrona em disco no JSON do perfil, haveria degradação extrema de I/O e stuttering visual.
   - *Mitigation:* `ProfileDebounceSaver` unifica todas as chamadas num timer de 500ms (`GLib.timeout_add`). As escritas em disco são atômicas e executadas apenas após cessar o movimento do usuário, ou imediatamente ao fechar o editor (`flush()`).
2. **Threat — System Hotkey Hijacking / Trapping (CWE-284):** O jogador poderia mapear acidentalmente `F1` (trava de mira), `F2` (abrir editor) ou `F3` (toggle OSD) para um botão de toque do jogo, impedindo que os atalhos globais operem e travando o cursor.
   - *Mitigation:* `OverlayCanvas` rejeita ativamente códigos de tecla `F1`, `F2` e `F3`, exibindo um `Adw.Toast` explicativo que orienta o jogador a usar outras teclas.
3. **Threat — State Corruption via Component Duplication (CWE-662):** Ter múltiplos controladores de mira FPS (`AimWidget`) ou analógicos virtuais (`DPadWidget`) ativos no mesmo perfil quebraria a injeção uinput com colisões de slot e comportamento errático da câmera.
   - *Mitigation:* Regra de instância única mandatória per D-08. Se o usuário tentar instanciar um segundo DPad ou Aim, o editor recentraliza a instância existente na coordenada alvo e exibe notificação sem criar duplicatas.
</threat_model>

             Define `self._pending_profile = None`.

           Retorna `GLib.SOURCE_REMOVE`.

           Se `self._source_id is not None`, cancela timer via `GLib.source_remove(self._source_id)`.
